## 2. Visual Branding & Corporate Colors

To satisfy the **Part 2** requirement of cohesive corporate colors across both the webpage and the PowerPoint presentation, a split palette balancing structural tech and creative design is utilized:

* **Primary Tech Color (Infrastructure, Security, Cloud):** Deep Corporate Navy (`#0A192F`) — represents trust, data stability, and security.
* **Secondary Tech Color (AI & Systems):** Electric Cyber Blue (`#00B4D8`) — represents innovation and digital intelligence.
* **Creative Accent Color (Graphics, 3D, Animation):** Neon Coral/Orange (`#FF5A36`) — represents imagination, visual rendering, and energy.
* **Background Neutrals:** Clean White (`#FFFFFF`) and Light Gray (`#F8F9FA`) for clean website readability.

## 3. Webpage Asset Specifications (Part 1 Blueprint)

### Logo Design
* **Format:** `PNG` with a transparent background (`colour to alpha`).
* **Elements:** Must contain both text and images.
* **Concept Idea:** The text "**ISACS**" written in a bold, clean sans-serif typeface next to a stylized, floating 3D wireframe cube or circuit node graphic using the corporate color palette.

### Marketing Banner
* **Format:** `JPEG`
* **Dimensions:** Exactly **1108 pixels (Length) × 277 pixels (Width)**.
* **Placement:** Positioned as a floating pop-up at the very top or bottom of the viewport upon page load.
* **Interactivity:** Must include a clear dismiss/close button (`X`) so the user can remove it, mimicking standard ad-removal functionality.
* **Content:** Advertise at least two core contrasting services. *Example copy:* "Securing Your Infrastructure. Animating Your Imagination. Next-Gen Cybersecurity meets Immersive 3D Production."

### Video Integration
* **Requirement:** A video thumbnail must be visible on the home page.
* **Interaction:** Clicking the thumbnail must trigger the actual video to play **inline on the same page** (e.g., embedding an HTML5 `<video>` tag or a modal popup, avoiding external redirections).

### Navigation Menu
* **Requirement:** A menu consisting of at least 5 items.
* **Hyperlink Status:** Unlinked (`href="#"` or unlinked tags as per prompt constraints).
* **Proposed Structure:**
  1. Home
  2. Managed IT & Cloud
  3. Cybersecurity
  4. AI & Creative Studios
  5. Contact Us

### Responsiveness
* **Implementation:** Use CSS Media Queries or a flexible fluid grid (like standard CSS Grid/Flexbox or built-in Drupal responsive themes) to ensure full layout adaptability across mobile, tablet, and desktop screens.
